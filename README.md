
# Enchanted-Osaurus

A fork of Enchanted by Augustinas Malinauskas (https://github.com/gluonfield/enchanted) that adds Osaurus (https://github.com/osaurus-ai/osaurus) agent support over end-to-end encryption plus chat rendering improvements.

Enchanted-Osaurus is an open source, [Ollama](https://github.com/jmorganca/ollama) AND Osaurus compatible, iOS app for working with locally or remotly hosted LLMs.
